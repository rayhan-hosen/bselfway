## 📌 অ্যাপের সংক্ষিপ্ত পরিচয় (Overview)

<p align="center">
  <img src="images/bselfway-image.png" alt="bSelf Way Banner" width="380">
</p>

**bSelf Way** (`bselfway`) একটি **Free Payment Gateway** এবং **Payment Automation Bangladesh** টুল, যা বিশেষ করে অনলাইন উদ্যোক্তা, SAAS ফাউন্ডার, ই-কমার্স এবং ডিজিটাল প্রোডাক্ট সেলারদের জন্য তৈরি করা হয়েছে। 

এই অ্যাপটির মাধ্যমে আপনার সাধারণ অ্যান্ড্রয়েড ফোনটিকেই একটি **Free bKash Gateway** এবং **Payment Gateway App Free** হিসেবে ব্যবহার করতে পারবেন। অতিরিক্ত কোনো Gateway কমিশন বা থার্ড-পার্টি সার্ভিস ফি ছাড়াই প্রতিটি বিকাশ পেমেন্ট এবং TrxID অটোমেটিক ভেরিফাই করে কাস্টমারের অর্ডার মুহূর্তেই অটো-অ্যাপ্রুভ করতে পারবেন—**Zero Cost**, **100% Safe** ও **Secure** উপায়ে।

## 🌟 কেন bSelf Way আপনার বিজনেসের জন্য Best?

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│     bKash Customer        │      │    bSelf Way Gateway      │      │    Your Business Server   │

└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
```

* **💰 0% Service Charge (Zero Cost):** কোনো ট্রানজেকশন ফি বা মান্থলি সাবস্ক্রিপশন চার্জ নেই। আপনার উপার্জনের ১০০% টাকাই আপনার কাছে থাকবে।
* **⚡ 100% Automatic Approval:** কাস্টমার সেন্ড মানি বা পেমেন্ট করলেই সিস্টেম স্বয়ংক্রিয়ভাবে TrxID ও টাকার পরিমাণ মিলিয়ে অর্ডার অটো-অ্যাপ্রুভ করবে।
* **🔒 100% Safe & Secure ("Your Data, Your Wealth"):** আপনার পেমেন্ট বা ট্রানজেকশন ডেটা কোনো থার্ড-পার্টি সার্ভারে সংরক্ষণ করা হয় না। সমস্ত ডেটা আপনার নিজস্ব ফোনেই এনক্রিপ্ট থাকে এবং সরাসরি আপনার সার্ভারে পোস্ট হয়।
* **📉 বিজনেসের পরিচালন খরচ কমায়:** ম্যানুয়াল মেসেজ চেক করার ঝামেলা ও অতিরিক্ত কর্মী রাখার খরচ বেঁচে যায়, যা ব্যবসার লাভজনকতা বাড়ায়।
* **🔋 24/7 Continuous Background Engine:** ফোন মিনিমাইজ করা থাকুক বা স্ক্রিন বন্ধ থাকুক, এটি ২৪/৭ ব্যাকগ্রাউন্ডে অনবরত কাজ করে। এমনকি ফোন রিবুট (Reboot) হলেও সার্ভিসটি স্বয়ংক্রিয়ভাবে চালু হয়।
* **🌐 অফলাইন স্টোরেজ সুবিধা:** ইন্টারনেট সংযোগ বিচ্ছিন্ন থাকলেও পেমেন্টের তথ্য ফোনে নিরাপদে সেভ থাকে এবং ইন্টারনেট আসামাত্রই অটো-সিঙ্ক হয়ে আপনার সার্ভারে পৌঁছে যায়।

## 📦 Payload Structure

```http
POST /v1/bkash-webhook HTTP/1.1
Host: api.yourdomain.com
Content-Type: application/json
Authorization: Bearer YOUR_SECRET_BEARER_TOKEN
```

```json
{
  "amount": "500.00",
  "from": "01700000000",
  "trx_id": "AAAAAAAAA",
  "date_time": "24/09/2026 01:15"
}
```
