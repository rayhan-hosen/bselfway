# bSelf Way 🚀
### Personal bKash Transaction Saver & Cloud Backup Automation

> **আপনার ব্যক্তিগত বিকাশ ট্রানজেকশন তথ্য স্বয়ংক্রিয়ভাবে নিজের পার্সোনাল ক্লাউড স্টোরেজে সেভ করার ইউটিলিটি টুল! ১০০% নিরাপদ, প্রাইভেট ও সহজ ব্যবহার।**

> [!IMPORTANT]
> **জরুরী ঘোষণা (Disclaimer):**
> **bSelf Way কোনো Payment Gateway (পেমেন্ট গেটওয়ে) বা Payment Aggregator (পেমেন্ট এগ্রিগেটর) টুল নয়।** এটি সম্পূর্ণভাবে ব্যক্তিগত ব্যবহারের (Personal Use) জন্য তৈরি একটি অ্যান্ড্রয়েড ইউটিলিটি অ্যাপ। নিজের ব্যক্তিগত বিকাশ লেনদেনের তথ্য সহজে, দ্রুত এবং স্বয়ংক্রিয়ভাবে পার্সোনাল ক্লাউড স্টোরেজ (Personal Cloud Storage) বা নিজস্ব API Endpoint-এ সংরক্ষণ ও ব্যাকআপ রাখার উদ্দেশ্যে এই টুলটি বানানো হয়েছে।

**bSelf Way** (`bselfway`) একটি ওপেন-সোর্স পার্সোনাল অটোমেশন অ্যাপ। আপনার ডিভাইসে আসা বিকাশ ট্রানজেকশন সংক্রান্ত SMS-এর তথ্য স্বয়ংক্রিয়ভাবে পার্স করে তা আপনার নিজস্ব ক্লাউড স্টোরেজ বা পার্সোনাল সার্ভারে সেভ করে রাখে, যা আপনার ব্যক্তিগত হিসাবরক্ষণ ও কাজকে অনেক সহজ ও দ্রুততর করে তোলে।

## 🌟 কেন bSelf Way ব্যবহার করবেন?

```
┌───────────────────────────┐      ┌───────────────────────────┐      ┌───────────────────────────┐
│     Personal bKash SMS    │      │    bSelf Way App (Local)  │      │   Personal Cloud Storage  │
│  Personal Transaction     │ ───> │ Parses bKash SMS on Phone │ ───> │ Stores Transaction Data   │
└───────────────────────────┘      └───────────────────────────┘      └───────────────────────────┘
```

* **⚡ ১০০% স্বয়ংক্রিয় ডাটা সেভিং:** পার্সোনাল বিকাশ ট্রানজেকশন হওয়া মাত্রই ট্রানজেকশন আইডি (TrxID), টাকার পরিমাণ ও সময় অটোমেটিক আপনার পার্সোনাল ক্লাউড স্টোরেজে সেভ হয়ে যায়।
* **🛠️ নিজের কাজ সহজ ও দ্রুত করে:** ম্যানুয়ালি মেসেজ দেখে ট্রানজেকশন নোট ডাউন করার ঝামেলা দূর করে ব্যক্তিগত কাজের গতি বাড়ায়।
* **🔒 100% Safe & Secure ("Your Data, Your Wealth"):** আপনার কোনো পেমেন্ট বা ট্রানজেকশন ডেটা কোনো থার্ড-পার্টি সার্ভারে সংরক্ষণ করা হয় না। সমস্ত ডেটা আপনার ফোনেই প্রসেস হয় এবং সরাসরি আপনার নিজস্ব ক্লাউড স্টোরেজে পাঠানো হয়।
* **💰 সম্পূর্ণ বিনামূল্যে (Zero Cost):** এটি কোনো বাণিজ্যিক সার্ভিস নয়, তাই এতে কোনো ফি বা সাবস্ক্রিপশন চার্জ নেই।
* **🔋 24/7 Continuous Background Engine:** ফোন স্ক্রিন বন্ধ থাকলেও বা ব্যাকগ্রাউন্ডে অ্যাপ চলাকালীন এটি অনবরত কাজ করে। এমনকি ফোন রিবুট (Reboot) হলেও সার্ভিসটি স্বয়ংক্রিয়ভাবে চালু হয়।
* **🌐 অফলাইন স্টোরেজ সুবিধা:** ইন্টারনেট সংযোগ না থাকলেও ট্রানজেকশন তথ্য ফোনে নিরাপদে সেভ থাকে এবং ইন্টারনেট চালু হওয়া মাত্রই পার্সোনাল ক্লাউডে অটো-সিঙ্ক হয়ে যায়।

## 🚀 দ্রুত সেটআপ গাইড (Quick Setup Guide)

### স্টেপ ১: অ্যাপ ডাউনলোড ও পারমিশন
1. আমাদের [GitHub Releases](https://github.com/rayhan-hosen/bselfway/) থেকে `bSelf Way` APK ডাউনলোড করে ইনস্টল করুন।
2. অ্যাপটি খুলে **`SMS`** পারমিশন অ্যালাউ (Allow) করুন।
3. ব্যাকগ্রাউন্ডে অনবরত সার্ভিস চালু রাখতে **Background Battery Optimization** পারমিশন দিন।
